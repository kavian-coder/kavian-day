# 世界 v2 概念稿 · 热带海岛小镇

2026.10.29 第一批。图在 ChatGPT 的对话「生成岛屿小镇图像」里（共 9 张，暂不下载进项目），提示词见 `prompts.md`。

## 为什么要改

现在的岛是“挺好看的通用小岛”：外圈一条铁路、中间树林、几座散点小屋、一条河。问题有三个：

1. 地形层次少，没有“海 → 礁 → 沙滩 → 港口 → 小镇 → 山”的递进。
2. 建筑和内容没有绑定，看不出每栋房子是干什么的、和你有什么关系。
3. 没有记忆点。看完记不住任何一个地方。

## 方向

热带、海边、小镇生活、旅行感，带一点数码和创作的工作室气质，再加上潜水、户外、健身、影像这些爱好，和狗、猫一起生活。既能放作品，也能放生活。

规则：**每个地标 = 一个栏目 = 你的一部分。** 地标的位置要说得出理由。

| 地标 | 栏目 | 为什么在这里 |
|---|---|---|
| 海边车站 | 入口、目录 | 访客坐小电车“到达”这个世界，旅行感从这里开始 |
| 海港工作室（旧船屋改的） | 作品、项目 | 数码和创作的工作间，面朝港口，作品像停靠的船 |
| 山坡上的家和院子 | 关于我 | 你和柴犬、猫生活的地方，能俯瞰小镇和海 |

1. 海边车站：傍晚金光，站台就在海边，柴犬坐在站台上等车，咖啡亭、自动贩卖机、单车，远处是坡上的小镇和灯塔。

6. 夜晚小镇街道：坡道通向月光下的港口，书店咖啡、照相馆、冲浪健身俱乐部、亮着的自动贩卖机，头顶挂灯串，猫坐在墙上。

### 我的家

两层白墙木饰面、蓝绿瓦屋顶，朝海的大玻璃推拉门和木平台。

- 一层：客厅（沙发、唱片机）、厨房岛台、玄关装备墙（脚蹼、潜水服、面镜、冲浪板、单车）、狗窝和猫爬架。
- 二层：工作间（双屏、相机柜、无人机、照片墙）、健身角（引体向上架、壶铃、瑜伽垫）、卧室（临海的窗边座）。
- 屋顶：吊床、灯串、望远镜。
- 院子：户外淋浴、香草种植箱、小菜地、石墙、石阶通向小镇。
- 柴犬和猫住在这里，平时在院子和屋里活动。

做进 3D 时，家是唯一可以“走进去”的室内：剖面图那样的二层结构，进门后镜头切到室内视角。

### 细节和品质的要求（以后每一步都按这个验收）

- 树叶：一片片的叶子，有叶脉明暗，随风摆；雨后叶面有水珠、叶尖滴水。
- 雨：雨丝、地面变湿变亮、水坑有涟漪和倒影、屋檐滴水、雨链流水，雨停后慢慢变干。
- 水：海水通透、能看到礁石和鱼；夜里礁石边有淡蓝的光。
- 灯光：夜里窗户、灯串、路灯、摩天轮都会亮，灯光照在湿地面上有反射。
- 不能有：穿模、物体互相插进去、悬空、闪烁、镜头钻进物体、动物或人穿过墙和家具。每加一个东西，都跑一遍自动检查（静态穿插、路线可走、动物重叠）。

- 北边是雨林山脊，山顶约 60 米，中间一道瀑布落进水潭；溪流穿过小镇，从石砌码头中间流进海湾，过两座小拱桥。
- 铁路重画：沙洲 → 湾口跨海桥 → 东岬 → 跨海桥上露营岛 → 北岸（山下走隧道）→ 西边回到沙洲。跨海桥是混凝土拱桥，桥墩立在海底。
- 坡地小镇：房子的地块先在 `layout.ts` 里定好，地形按地块挖平、填平，房子坐在平地上，地块之间自然形成台地；门口比街面高就自动加台阶。白墙、淡彩墙，陶红瓦或青绿瓦，木百叶、阳台、小店的条纹遮阳篷、平屋顶的水箱、墙角的三角梅。
- 港口：海湾北岸是石砌码头墙和栏杆，6 座木码头，两边停着渔船、游艇、小木船，湾里还漂着几条，都会随浪起伏，彼此不会碰到。
- 植被换成热带：雨林大树冠的阔叶树夹着椰子树，开花树是火红的凤凰木，海边成片椰子树。
- 瀑布：竖着往下流的水帘（浅青和亮白两档条纹），落点有升起的水雾。
