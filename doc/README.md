# doc

项目的规划、分析和设计文档都放在这里，按主题分文件夹。新的分析文件也放进来，不再放到别处。

| 文件夹 | 内容 |
|---|---|
| `design-system/` | 设计系统的文字版：使用规则、喜好分析、世界美术规范、工程约定、决策记录、角色出图提示词、AI 建模方案、世界概念 |
| `characters/` | 角色相关：`refs/` 是风格参考图（只在内部用，不放上网站）；定稿的设定图和透明底图也放这里 |

约定：

- 文件名用"序号-主题.md"，序号表示阅读顺序。
- 重要决定写进 `design-system/04-决策记录.md`：改了什么、为什么、替代了什么。
- 颜色、时段、季节、天气的数值不要写在文档里，以 `packages/tokens/` 为准。
