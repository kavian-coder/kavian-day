# 世界美术规范

v0.3 起，世界是实时 3D，用卡通渲染（三渲二）做出日系动画的感觉：角色像吉卜力、新海诚电影或《旷野之息》里的人物，场景是小尺度的海岛和聚落，光照、天气、四季都实时计算。访客用键盘控制你的角色走动，靠近地点按 `E` 互动。下面的数值是起点，第一个可走场景做完后按实测调整并记入决策记录。

## 画风

- **卡通渲染**：角色和场景都用 2–3 级色阶的卡通着色，加柔和的边缘光；角色有细描边，场景物体不描边或只描很淡的边。
- **光是主角**：白天强烈的阳光和清楚的投影，树下有光斑；黄昏粉橙逆光；夜晚蓝紫色的天空、星星、暖色的窗和灯串。夜晚不能黑到看不清路。
- **天空和云**：天空用渐变穹顶加手绘风的积云（贴图或体积云片），不用写实天空盒。云的背光面偏蓝紫。
- **饱和但通透**：主色取 `world-*` 与 `pal-*`；远处加 `world-haze` 的空气透视；阴影偏青紫，不出现纯黑和中性灰。
- **小尺度、有人住**：像模型一样精致的小岛和聚落，有码头、车站、小屋、灯串、晾衣绳这类生活细节。

## 世界结构

- 每个场景是一块独立的小地图（海边车站、坡道小镇、栈桥码头、林间书屋、小屋……），之间用路口、门或列车连接，切换时淡入淡出加载。
- 首版只做一个场景，其他出口挂"施工中"。
- 每个场景有自己的网址，可以直接分享，打开时角色出现在默认出生点。

## 镜头与操作

- 第三人称跟随，默认斜俯视约 45°，可以鼠标拖动旋转、滚轮在限定范围内缩放；有"回到默认视角"。
- `W` `A` `S` `D` 移动，`Shift` 跑，`E` 互动或进门。手机上点按地面寻路。
- 镜头被树或房子挡住时，遮挡物淡化。

## 时段、季节、天气（实时 3D 的做法）

- **时段**：按 `data/time-phases.json` 混合四套 `world-*` 颜色，驱动太阳方向和颜色、环境光、天空渐变、雾和水色；窗光、路灯、灯串按 `windows` 强度点亮。
- **季节**：海边常夏，只换花朵和光线；山间换树叶材质颜色（嫩绿、浓绿、红黄），冬天加积雪材质和落雪粒子。规则在 `data/seasons.json`。
- **天气**：云量调天空和光照强度，雨雪雾是粒子和雾，雨天地面变湿反光、加水洼，雷雨时闪电照亮天空。规则在 `data/weather.json`。
- 这些都是实时参数，**不需要为每个时段、季节和天气单独画图**。

## 角色

- **风格**：吉卜力 / 新海诚 / 旷野之息式的动画电影人物：头身比约 1:6.5，眼睛小而简单，细线，平涂加一层阴影，颜色朴素。3D 版的参考是《二之国》和《旷野之息》。挑图标准和出图方法见 `05-角色出图提示词.md`。
- **外观从你本人提炼**：发型、眼镜（如有）、常穿的衣服轮廓、一两件标志性配件。需要你提供正面、侧面、全身的参考照片。
- **流程**：AI 出电影画面定人物 → 出白底三视图（正、侧、背）→ 3D 建模 → 导入网页。建模方式等平面定稿后再定：VRoid（默认是大眼睛手游脸，需要重画眼睛和脸部贴图）、Blender 手工建模，或找建模师。
- **动画**：从 Mixamo 取待机、走、跑、坐、挥手、互动等动作，重定向到 VRM 骨骼。待机里加偶尔的小动作（看天、伸懒腰）。
- **换装**：按季节四套，默认夏季：春是长袖 T 恤或衬衫配长裤，夏是 T 恤、短裤、拖鞋，秋是卫衣（或 T 恤加外套）配长裤，冬是羽绒服、围脖、长裤。宽松的 city boy 风（oversize 上衣 + 阔腿裤），每季一组配色（春 条纹衬衫 + 浅色牛仔，夏 白 + 晴空蓝，秋 深棕夹克 + 米白阔腿裤，冬 藏青短羽绒服 + 红围脖 + 灰阔腿毛呢裤），衣服要有面料质感，不戴配件，越轻松越好。设定图见 `doc/characters/`。服装按部件拆开建模（上衣、外套、下装、鞋、围脖），共用一副骨骼，季节切换时自动换成当季那套；以后在这个基础上做衣橱系统，自由搭配。

## 宠物

- 默认是狗，访客可以换成猫，选择保存在访客本地。
- 风格和角色一致：像吉卜力电影里的动物，形体简单圆润、小眼睛、平涂加一层阴影。不戴项圈、方巾等配饰。
- 狗是奶油橙色柴犬（已定稿）；猫是奶白底、暖灰大花斑的胖猫。
- 动物不能用 VRoid 和 Mixamo（它们只做人形），要在 Blender 里建模并绑定四足骨骼，或者买现成的卡通动物模型再改颜色。
- 动画：待机、走、跑、坐、嗅闻。行为：跟在角色身后，角色停下它会坐下等待，偶尔去看附近的东西，不挡门和交互物。

## 建筑、植物、道具

- 用 Blender 建模，或先用 AI 3D 生成工具（如 Tripo、Meshy、混元 3D）出粗模，再在 Blender 里减面、统一比例和上色。
- 统一用一张或几张调色板贴图上色（颜色取 `pal-*`），这样换时段时整体染色一致，也省贴图。
- 窗户、灯具、灯串做成单独的自发光材质，夜晚点亮。
- 地点名不做成 3D 文字，由界面层的 `PlaceLabel` 显示，方便改名和双语。

## 资产规范

- 单位：1 单位 = 1 米，角色身高约 1.72，柴犬肩高约 0.39，猫背高约 0.25。比例对照图见 `doc/characters/v0.5/02-比例对照`。
- 格式：角色 `.vrm`，其余 `.glb`（网格用 meshopt 压缩，贴图转 KTX2）。
- 命名：`env_`（环境）、`bld_`（建筑）、`prp_`（道具）、`chr_`（角色）、`pet_`（宠物）、`fx_`（特效），小写加下划线，例如 `bld_station_a`、`pet_dog_shiba`。
- 每个资产先做一个灰模占位，场景搭好再替换。
- 保存 AI 生成用的提示词、参考图和模型版本，方便以后补同风格的资产。

## 性能预算（起点，待实测）

| 项目 | 桌面 | 手机 |
|---|---|---|
| 首个场景下载量（压缩后） | ≤ 10 MB | ≤ 5 MB（降一级贴图） |
| 角色 + 宠物 | ≤ 4 MB | ≤ 4 MB |
| 三角面 | ≤ 30 万 | ≤ 12 万 |
| 绘制调用 | ≤ 150 | ≤ 80 |
| 目标帧率 | 60 | 30 |

持续低帧率时按顺序降级：像素比 → 阴影精度 → 粒子数量 → 后期效果（泛光）→ 远景物体。
