# （v1）世界概念：海岛

v1.2 · 2026.10.29。代码在 `packages/world/src/`，地形、地点、道路的坐标都写在 `layout.ts` 里。

## 一句话

一座不规则的圆形海岛，一条环岛小电车绕着海岸跑。从海边站下车，沿小路走进岛里，每一处地点对应网站的一个栏目。

## 地图

| 方位 | 内容 |
|---|---|
| 岛外 | 一圈浅浅的珊瑚礁（水很透，能看到沙底、焦散、珊瑚和鱼），再往外是深海，海平线上有几座远岛 |
| 南 | 海湾、沙滩、栈桥和小灯塔，海边常年是夏天 |
| 沿岸 | 环岛铁路；北边过山的地方走隧道；海边站是入口，旁边有道口 |
| 中 | 石板广场和一棵大樟树，是岛的中心 |
| 西 | 溪流和红色木拱桥，过桥是树林里的林间书屋 |
| 东 | 造物间（木工房）和试验棚（玻璃温室） |
| 北 | 小坡上的小屋（关于我），再往北是针叶林和雪山，山一直延伸到北岸 |

## 会动的东西

- 小电车：两节车厢，绕岛一圈一圈地开，每圈在海边站停 8 秒，过北边的山时钻进隧道。车快到时道口的红灯会闪，栏杆会放下。
- 溪水往下游流，山里坡陡的地方有白色急流。
- 海浪是一道道往岸上推的白线。浅水是透明的，能看到下面的沙子。
- 树、草、花、床单都会随风摆，风力跟着天气变。
- 小屋烟囱冒烟，秋千在晃，小船在栈桥边起伏，海鸥在海面上空绕圈。
- 夜里：窗户、路灯、自动售货机会亮，路灯有光晕，灯塔的光柱扫过海面。夏夜溪边有萤火虫。

## 四季

海边一年到头都是夏天，只有内陆和山里换季。

| 季节 | 变化 |
|---|---|
| 春 | 嫩绿的草和树，樱花开，花多，空中飘花瓣 |
| 夏 | 浓绿，蓝紫色的花，夏夜有萤火虫 |
| 秋 | 草变成金黄，阔叶树变成橙红，溪边有红色的花，空中飘落叶 |
| 冬 | 内陆铺满雪，阔叶树和樱花只剩枝干，针叶树挂霜，樟树常绿 |

## 画面做法

全部是实时 3D，不用贴图，颜色都是顶点色或纯色，所以体积很小。

- 三渲二：明暗分三档，影子只压暗一层，不压到发黑。
- 树冠的法线做成从中心往外，一团叶子像一个整体那样受光，接近动画背景里树的画法。
- 描边：后期按深度找物体轮廓，线的颜色是底色压暗，不是纯黑。
- 水：从地形高度图读水深，浅处透明发青，深处变蓝，岸边有泡沫和浪线。
- 天空：渐变加太阳光晕；海平线上有几座远岛的剪影；晴天能看到太阳，夜里有月亮。
- 云（v1.3 起）：不再是 3D 网格，直接画在天空球的着色器里（`sky.ts`）。一层随风飘的积云 + 海平线上一圈积雨云塔，云量和云塔高度跟着天气变，靠近太阳的云边会亮起来，云能挡住太阳和月亮。天空球跟着镜头走，所以云永远不会和山、灯塔、镜头穿插。
- 后期统一调色和暗角。时段、天气的颜色仍然由 `packages/tokens` 的世界色板决定。

## 生态

每种生物都有自己的作息，跟着时段、季节、天气出现或躲起来（`eco.ts` 把环境换算成白天、夜晚、晨昏、雨雪等几个数，各物种按自己的习性算出活跃度）。

| 生物 | 什么时候多 | 什么时候没有 |
|---|---|---|
| 鱼群（6 群，不同颜色） | 一直都在礁盘上绕岛游 | 夜里少一半、游得更深；冬天少一些 |
| 海龟 | 春夏 | 冬天几乎不见 |
| 海豚 | 白天在外海跃出水面 | 夜里、暴风雨 |
| 鲸 | 冬春洄游季，远海换气喷水 | 夏秋少见 |
| 水母 | 夏秋在海湾里漂，夜里发光 | 冬天 |
| 螃蟹 | 傍晚和夜里在沙滩上横着走 | 下雨、冬天 |
| 蝴蝶 | 春夏白天的花丛 | 夜里、下雨、冬天、大风 |
| 蜻蜓 | 夏秋白天的溪边 | 夜里、下雨、冬天 |
| 小鸟 | 清晨最热闹，在树梢之间飞 | 夜里、下雨 |
| 雁阵 | 秋天往南、春天往北飞过 | 夏冬、夜里 |
| 鹿 | 黎明黄昏出来吃草，冬天换灰毛 | 深夜、暴雨 |
| 兔子 | 晨昏和白天，冬天变白 | 深夜、下雨 |
| 青蛙 | 春夏溪边，下雨和夜里最多 | 冬天 |
| 萤火虫 | 夏夜溪边，初秋少一些 | 白天、下雨 |
| 飞蛾 | 夏秋夜里围着路灯 | 白天、下雨 |
| 海鸥 | 白天在海面上绕圈 | 夜里、暴风雨 |

### 动物之间的反应（v1.3）

每只动物都会看周围的“威胁”：角色（走动时威胁更大）、狗、开过来的列车。离得越近反应越大，不需要一个个手写规则。

| 生物 | 反应 |
|---|---|
| 狗 | 平时跟着角色；角色停下来后，会去追 8 米内的螃蟹、兔子、青蛙，对方钻沙或跳水后就去那里闻一闻；看到鹿只站着盯；小动物贴到身上会吓一跳往后蹦开，再盯一会儿；列车开近也会吓一跳蹦到铁轨外；角色一走远就放下一切跟上 |
| 螃蟹 | 角色或狗靠近（约 3.5 米）就横着往海里跑，跑到一半钻进沙里，过 8–18 秒在离角色和狗至少 7 米的地方再钻出来；被碰到也会立刻逃 |
| 鹿 | 13 米内抬头警戒，7 米内跑开，绕开树和石头 |
| 兔子 | 8 米内立起来张望，4.5 米内蹦着逃开 |
| 青蛙 | 3 米内跳进溪里，12–22 秒后再出来 |
| 小鸟 | 5.5 米内从树上惊飞，落到 10 米外的另一棵树上 |
| 蝴蝶、蜻蜓 | 靠近时让开、突然飞走 |
| 鱼群 | 角色走到浅水边时散开 |
| 鱼、海龟、水母、珊瑚 | 绕开栈桥和灯塔的柱子 |

自然的变化：

- 下雨：天变暗，地面变深、低洼处有反光的水洼，海面和溪面有雨滴涟漪，风变大、树草摆得更厉害。
- 下雪 / 冬天：内陆铺雪，屋顶积雪，阔叶树落光，针叶树挂霜，兔子变白。
- 起雾：雾拉近，动物变少。
- 晴天：太阳随时段移动（清晨东边、中午南偏西、傍晚西边海上），海上有一条阳光闪光带；云影飘过地面；浅海底有焦散亮纹。
- 夜里：主光换成北边天空的月光，窗户、路灯亮起，灯塔光柱扫过海面。

## 操作

键盘只管角色和视角，镜头全部交给鼠标 / 触控板（v1.3）。

| 键盘 | 作用 |
|---|---|
| W / ↑ | 往前走（朝镜头看的方向） |
| S / ↓ | 往后退；角色视角下是倒着走，镜头不会转 |
| A D / ← → | 往左、往右走 |
| Shift | 跑 |
| V | 切换上帝视角和角色视角 |
| E | 在地点旁进入（也可以直接点屏幕上的提示） |
| Esc | 关掉打开的面板；沉浸模式下退出沉浸 |

| 鼠标 / 触控板 | 作用 |
|---|---|
| 上帝视角：左键拖动、单指拖动、触控板双指滑动 | 平移，可以离开角色看整座岛 |
| 上帝视角：右键或 Alt + 拖动、双指旋转 | 转方向，上下拖改俯仰，可以转到正上方垂直往下看 |
| 角色视角：拖动 | 绕着角色转镜头，镜头不会自己转回去 |
| 滚轮、触控板捏合、双指捏合 | 缩放 |

镜头代码在 `camera.ts`。去掉了 F 键和镜头自动回正（之前在 Mac 上按 S 时镜头会自己转，就是自动回正造成的）。

## 界面（v1.3）

界面全部是“玻璃”：半透明加背景模糊，能透出后面的场景，颜色跟着时段的色板走。

- 左上：站点 logo（占位）+ 菜单。点菜单在下面滑出地点目录。
- 右上一个胶囊：时钟 / 天气 / 温度、视角切换图标、语言图标（显示 EN / 中）、设置图标。点时钟打开环境面板（预览别的时段、季节、天气；预览时才出现“回到现在”，平时显示“实时”）。
- 设置面板：视角切换、键盘说明、鼠标说明（按当前视角显示）、沉浸模式。原来左下角的操作提示合并到这里，第一次访问时左下角只出现 9 秒的简短提示。
- 同一时间只开一个面板；点场景或按 Esc 关掉。面板有淡入和轻微位移的过渡。
- 沉浸模式：一键藏起所有界面并进入全屏，只留一个小的退出按钮；Esc 或退出全屏都会恢复界面。选这种而不是“只收起”，是因为看风景时最想要的是整块屏幕。

## 不穿模的做法（v1.3）

- 会动的东西都是地面上的一个圆（`bodies.ts`）：角色、狗、鹿、兔子、螃蟹、青蛙。每帧最后统一把重叠的圆按体重推开，轻的被推得多，被推的位置不能进障碍；列车车厢是会动的长方形，压在里面的身体会被推到铁轨两边。
- 静态障碍：树干、石头、房子、灯柱、长椅等道具在生成时按网格的包围盒自动算出碰撞圆，放进 4 米一格的网格里查询。
- 摆放时就避开：树、草、花不长在路上、铁轨边、房子和道具下面；路灯、电线杆不放在铁轨、溪流和平台上；樱花和溪边石头离路至少 2.2 米。`?debug` 下 `__kv.audit()` 检查静态穿插，`__kv.pathCheck()` 检查每条路能不能走通。
- 镜头：角色视角下镜头被房子、列车、树冠、地形挡住时会拉近，离角色太近时把角色隐藏，避免镜头钻进车站雨棚或角色身体里。
- 灯塔光柱：改成从灯头往外渐淡、边缘柔和的锥形光，不再是一根实心棱柱。
- 树冠净空（v1.3.1）：种树时拿每种树真实网格的顶点（按这一棵的朝向、大小摆好）逐点检查，碰到列车开过的空间（铁轨两边各 1.95 米、往上整个是空的）、电线和电线杆、房子的，这棵就不种。`__kv.audit()` 里的 `cleared-*` 是因此没种的数量。
- 电线：电线杆放不下的地方先沿铁路前后挪几米，实在放不下就让电线断开，不再隔着几十米拉一条斜穿陆地的直线。
- 溪流入海口（v1.3.1）：溪面在离海 10 米内平缓地降到海面；离海 10 米以外河床不低于海面，免得海水从河道底下透出来；溪面一直铺到岸线外 3 米，在岸线前后慢慢变透明，和海水接上。溪水在海水之后画、不写深度。

## 精细度的做法（不建模也能慢慢加）

v1.1 起这些都是程序生成的，不用贴图文件：

- 树冠：一层暗一些的“芯”负责投影子，外面贴上百片朝向镜头的叶片卡，叶片图是用代码画的一簇小叶子。
- 草：每丛 12 根弯叶，根部暗、叶尖亮，按地块分开，镜头外的不画。
- 表面花纹：瓦片、木板、灰泥、石块、地砖、碎石、车身接缝、树皮，都在着色器里按物体自己的坐标算出来（`kit.ts` 的 `pattern`）。
- 地面：大块深浅、斜向刷痕、细颗粒，局部偏暖或偏冷，像水彩背景。
- 后期：环境光遮蔽（缝隙和墙脚压暗）、飘过地面的云影、灯光泛光。
- 水：海面有平面反射（岛、树、云倒映在海上）、波浪法线、阳光高光；浅水几乎透明，海底有焦散；雨天有涟漪。
- 针叶树也改成锥形的芯加针叶卡；房子加了屋脊、封檐板、墙角柱、踢脚和窗台花箱。
- 烟：柔边的圆片，越往上越大越淡。

继续打磨的方向：给建筑加屋檐、窗框、门廊等小结构；列车加车门、受电弓细节；角色、宠物、车站这类主角物件用 Hyper3D 生成后替换。
